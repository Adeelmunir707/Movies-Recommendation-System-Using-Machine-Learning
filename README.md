  # 🎬 Movie Recommendation System

A Machine Learning-based movie recommendation system that suggests similar movies based on user input using content-based filtering.

## 🚀 Features
- Recommend movies based on similarity
- Fast and simple interface
- Uses cosine similarity & vectorization

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn

git clone https://github.com/Adeelmunir707/Movies-Recommendation-System-Using-Machine-Learning
